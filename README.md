## Technologies <a name = "techno"></a>

This project is made in html, css, javascript. The java-script respects the ES6 norm with the use of flexboxes.

Finaly it respects the A11y norm with aria labels.

It also implements Fisher-Yates algorithm for the shuffle of the cards and also asynchronism in the checkmatch function
